Perguntas Frequentes

Orientações objetivas sobre instalação, segurança e compatibilidade.

Como instalar o arquivo APK no Android? ▾
Após baixar o arquivo splithouse-v1.0.0.apk, abra o arquivo no gerenciador de downloads. Se solicitado, habilite a permissão para "Instalar fontes desconhecidas" no navegador ou gerenciador de arquivos e confirme a instalação.
O aplicativo funciona no iPhone (iOS)? ▾
Não. No momento, o SplitHouse está disponível exclusivamente para dispositivos Android (via pacote .apk), não possuindo versão para iPhone/iOS.
Como os dados e comprovantes são armazenados? ▾
Os registros de despesas, moradores e comprovantes são armazenados em nuvem com criptografia e controle de acessos por moradia, garantindo privacidade e isolamento dos dados de cada república.
É possível executar o pacote no emulador Android Studio? ▾
Sim. O pacote pode ser arrastado diretamente para uma instância ativa de emulador Android (API 24 ou superior) ou instalado via linha de comando com adb install splithouse-v1.0.0.apk.
Como novos moradores ingressam na república? ▾
Ao criar o cadastro da república, o administrador gera um código de identificação da casa. O morador convidado insere esse código no aplicativo para solicitar a entrada, que é aprovada pelo administrador no painel de membros.
